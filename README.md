# RIVA — Rasika's Personal OS

RIVA is a mobile-first PWA for daily planning, college timetable, skills, body progression, reminders and local personal data.

## GitHub Pages
1. Put these files at the repository root.
2. GitHub → **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then Save.
5. Open the generated Pages URL on Android.
6. Browser menu → **Add to Home screen / Install app**.

The app stores its personal state in the browser's localStorage. The repository contains the app code and the built-in timetable/template, not your live local task history.

## Important
GitHub Pages on GitHub Free requires a public repository. Do not put API keys, passwords, tokens or other secrets in this repository. RIVA's future AI backend should keep API credentials server-side.
